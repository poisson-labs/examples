# Poisson Labs examples

Worked examples on the Poisson Labs tools, each in a folder of its own with everything a reader
needs to run it. Each one is written up, with the output of a stored run, on
[poissonlabs.ai/docs/examples](https://poissonlabs.ai/docs/examples/).

| Folder | What it does | Tools |
|---|---|---|
| [`back-office-agent`](back-office-agent/) | An operations agent on Claude over a synthetic payments back office: a baseline audit, a model change on the same seeds, the comparison, and where the failures stop | Prove, Trace |

Every example runs on your own machine and, where it calls a model, on your own key, with its
cost stated before it spends.
